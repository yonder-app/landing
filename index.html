What is Homebrew?

Homebrew is a free package manager for Mac — it installs apps safely from the terminal. Run this once to install both Homebrew and Yonder:

Terminal.app
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" && brew install --cask yonder-app/tap/yonder

Yonder is downloading

  1. 1 When it's ready, open the file
  2. 2 Drag Yonder to your Applications folder
  3. 3 Launch Yonder from Applications or Spotlight
  4. 4 If macOS asks, go to System Settings → Privacy & Security and click Open Anyway
